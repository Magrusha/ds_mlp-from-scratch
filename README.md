# Реализация многослойного перцептрона (MLP) с нуля

Обучение нейронной сети для бинарной классификации рисков на данных автомобильных аукционов (Kaggle: Don't Get Kicked). Проект включает ручную реализацию алгоритма обратного распространения ошибки (backpropagation) и оптимизаторов без использования высокоуровневых фреймворков на этапе базовой реализации.

## Ключевые результаты
- Достигнут показатель **Gini ≥ 0.15** на валидационной выборке.
- Реализован собственный класс `MLP` с поддержкой методов `fit`, `predict` и `predict_proba`.
- Проведено сравнение производительности собственной реализации с `sklearn.MLPClassifier` и моделями на PyTorch/Keras с анализом причин расхождений.

## Стек технологий
- **Язык:** Python 3
- **Библиотеки:** NumPy (матричные операции и градиенты), Pandas (предобработка), Scikit-learn (метрики, базовые энкодеры), PyTorch/Keras (для сравнительного анализа).

## Что реализовано
1. **Предобработка данных:** 
   - Строгое временное разделение выборки по полю `PurchDate` (train < valid < test) для предотвращения утечки данных (data leakage) из будущего.
   - Кодирование категориальных признаков с учетом появления новых значений в валидации и тесте.
2. **Архитектура сети:** 
   - Полносвязная сеть с одним скрытым слоем.
   - Ручной математический вывод и программная реализация градиентов функции потерь (Log Loss / Binary Cross-Entropy) относительно весов и смещений.
3. **Функции активации:** 
   - Реализация и сравнение Sigmoid, ReLU и Cosine с ручным расчетом их производных для backpropagation.
4. **Оптимизация:** 
   - Базовый стохастический градиентный спуск (SGD) с мини-батчами.
   - *(Бонус)* Реализация оптимизатора Adam для ускорения сходимости и обхода локальных минимумов.
